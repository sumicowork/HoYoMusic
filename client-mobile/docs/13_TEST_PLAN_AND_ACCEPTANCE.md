# 13 - 测试计划与验收标准（Android）

## 1. 测试目标

确保 Android 客户端在网络波动、接口异常、播放切换等场景下保持稳定。

## 2. 测试层次

## 2.1 单元测试

建议覆盖：

- Envelope 解析器
- ErrorMapper
- 播放模式状态机
- 播放上报 session 管理

## 2.2 集成测试

建议覆盖：

- Repository + Fake API
- 登录/会话恢复
- 列表分页

## 2.3 手工回归

每次里程碑至少执行 15 条回归项。

## 3. 手工回归清单（建议）

1. 启动 app，健康检查显示正常。
2. 曲目列表加载成功。
3. 搜索关键字可返回结果。
4. 打开曲目详情并显示封面。
5. 点击播放后有声音输出。
6. 暂停/继续功能正常。
7. 拖动进度条后播放位置正确。
8. 下一首/上一首行为正确。
9. 切换到 `shuffle` 后随机策略生效。
10. 切换到 `single` 后单曲循环生效。
11. 切歌时触发上报（可观察日志）。
12. 断网时提示友好，不崩溃。
13. 恢复网络后可继续播放。
14. 登录成功后能读取 `/auth/me`。
15. 手动使 token 失效后，401 能触发重新登录流程。

## 4. 异常专项测试

### 4.1 429 限流

- 预期：提示“请求过于频繁”，并停止高频重试。

### 4.2 503 维护

- 预期：展示维护提示，不阻断基础导航。

### 4.3 404 资源缺失

- 预期：封面降级占位图，音频失败自动处理。

## 4.4 新增能力回归（2026-04-10）

1. 匿名状态进入“收藏”页时，应跳转登录并有提示。
2. 匿名状态在曲目列表点“收藏”，应触发登录引导。
3. 匿名状态在曲目详情点“加入歌单”，应触发登录引导。
4. 登录后可正常拉取收藏列表分页。
5. 收藏页关键字筛选可命中标题与专辑。
6. 收藏页排序（最新/A-Z/Z-A）可即时生效。
7. 收藏页“取消收藏”后列表项应移除。
8. 收藏页“下载”应在下载中心出现任务。
9. 收藏页“加入歌单”可打开歌单选择器并加入成功。
10. 曲目列表“收藏”状态应基于 checkFavorites 回填。
11. 曲目列表“加入歌单”可新建歌单并自动加入。
12. 曲目列表无结果时展示空态文案。
13. 曲目详情应展示播放数与收藏数。
14. 曲目详情来源为空时展示“暂无来源信息”。
15. 曲目详情加入下载后应提示“已加入下载队列”。
16. 歌单页匿名访问应触发登录引导。
17. 歌单列表支持搜索、名称排序、曲目数排序。
18. 歌单列表无数据时展示空态文案。
19. 歌单详情支持曲目搜索与排序。
20. 歌单详情移动曲目后顺序应保持。
21. 下载中心应显示活跃/完成/失败/取消计数。
22. 下载中心支持筛选（全部/进行中/已完成/失败）。
23. 下载中心支持排序（最新/最早/名称）。
24. 下载中心“清理失败”应移除失败项。
25. 下载中心任务空列表时应展示空态文案。
26. 已完成任务再次下载同曲目应被去重阻止。
27. 进行中任务再次下载同曲目应被去重阻止。
28. 401 响应后 Settings 会话状态应转为 Anonymous。
29. Settings 页面在线状态变化应实时更新。
30. Settings 页面会话状态字符串应跟随 SessionState 变化。

## 5. 性能观察项

- 首屏加载时间（冷启动）
- 列表滚动流畅度
- 播放切歌首帧时延
- 内存占用趋势（长时间播放）

## 6. 日志建议

- 网络请求关键日志（仅 debug）
- 播放状态转换日志
- 上报请求结果日志（脱敏）

## 7. 验收标准（MVP）

满足以下条件视为可进入 Beta：

1. 核心播放闭环稳定。
2. 崩溃率低，未发现阻断级问题。
3. 主要接口失败有可读提示。
4. 回归清单通过率 >= 90%。

## 8. 缺陷分级建议

- P0：崩溃、无法播放、无法启动。
- P1：功能可用但严重影响体验。
- P2：一般功能缺陷。
- P3：UI 细节和文案优化。

## 9. 发布前最小动作

1. 执行全量回归。
2. 清理 debug 日志开关。
3. 校验 API base URL 环境配置。
4. 记录已知问题并同步版本说明。
