## 6. 技术债务与已知问题

| 问题 | 严重程度 | 说明 |
|------|---------|------|
| 无令牌刷新机制 | 中 | 令牌过期后需重新登录 |
| 播放器使用公网流直连 | 低 | 无重试/质量自适应策略 |
| 下载队列仅为内存脚手架 | 低 | `IDownloadService` 已定义但无真实文件传输 |
| 频谱条使用正弦波模拟 | 低 | 非真实音频频谱数据 |
| 图片同步加载 | 低 | 大量封面图可能导致 UI 卡顿 |
| 无 MSIX 打包 | 低 | 仅通过 `dotnet run` 启动 |
